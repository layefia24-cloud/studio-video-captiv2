# Studio vidéo CAPTIV

Kit (skill Claude) de montage vidéo STUDIO CAPTIV : Reels, TikTok, Shorts et vidéos 16:9, face caméra ou sans visage, avec voix IA, sous-titres et motion design, selon le look book (codes L1–L17, P1–P17, A1–A10, B1–B20, SS).

## Contenu

- `SKILL.md` : la méthode de travail et les instructions du skill.
- `references/` : look book en codes (`codes.md`), styles, cibles, checklist, exemples de config et vignettes de chaque code (`references/vignettes/`).
- `scripts/` : moteur de rendu (`engine.html`, `render.mjs`, `short.js`, `premium.js`), voix (`tts.py`), préparation (`prepare.py`), guide des références avec aperçus (`guide.py`) et polices (`fonts/`, licences dans `LICENCES.txt`).

## Utilisation

Voir `SKILL.md` pour la méthode complète (brief → plan → guide des références → fabrication → retouches).
